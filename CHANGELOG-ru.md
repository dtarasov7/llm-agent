# История изменений

## [Unreleased]

- Strata balanced использует medium с бюджетом рассуждений 2048; deep — high без отдельного бюджета. Общий max_tokens=8192 сохранён.
- Обновлены параметры sampling профилей Strata fast/deep по рекомендациям Qwen3.8-Flash-Next; добавлена проверка полей min_p, presence_penalty и repetition_penalty. Общий лимит ответа сохранён: 8192.

Изменения сгруппированы по выпущенным версиям. Версия приложения задана константой `APP_VERSION` в `coding_agent.py`.

## [1.2.0] - 2026-10-07

### Добавлено

- Backend Ollama и профили fast/deep с лимитом 8192; thinking переводится в reasoning_effort, неподдерживаемые расширения отклоняются.

- Параметры sampling в профилях: Strata deep использует temperature=0.6, top_p=0.95, top_k=20; значения проверяются, переход на fast удаляет их.

## [1.1.0] - 2026-10-07

### Добавлено

- LLM_PROFILES заменяет глобальные псевдонимы моделей: профили текущего backend задают модель, thinking, reasoning и max_tokens=8192. Для Strata по умолчанию fast; deep включает low с бюджетом 512. Применение полностью заменяет параметры, ручные изменения отмечаются, неподдерживаемые настройки отклоняются.

- Подтверждена живая совместимость со Strata (qwen3.8-flash-next-iq3_xxs, контекст 131072); описаны режимы reasoning, уровни effort, отдельный бюджет и приоритет переключателя off.

- Лимиты шагов 500/500 с параметрами --max-steps, --continue-steps и одноимёнными командами сеанса; распознавание команд в русской раскладке с исправлением аргументов.

- Цветовое выделение важных остановок и ошибок в терминале; сообщение о лимите шагов поясняет число обращений к LLM и продолжение через /continue.

- Раздельные счётчики символов рассуждений, текста и аргументов инструментов; имена начатых вызовов при генерации и остановке, без вывода содержимого.

- Потоковый приём SSE с индикатором прогресса, лимит ответа 8192 токена, `--max-tokens`, `/max-tokens` и `--no-stream`. Обрезанные ответы останавливают задачу без выполнения инструментов и автоповтора; большие задачи выполняются небольшими шагами.

- Сообщение о загрузке `AGENTS.md`, сведения об инструкциях в `/context` и `/compact`: сжатие текущей задачи с сохранением инструкций, skills, состояния и архива переписки.

- Проектные skills в `.agents/skills/<имя>/SKILL.md`: `/skills [ИМЯ]`, дополнение TAB, краткий каталог в задаче, явная загрузка по `$имя` и инструменты модели `list_skills`/`read_skill`; загруженные инструкции сохраняются при восстановлении задачи.
- Краткая суть запросов LLM, время получения ответов и параметр `--llm-timeout` для настройки ожидания чата.
- Терминальный редактор задач `/edit`: многострочная вставка, редактирование курсором, отправка по Alt+Enter, отмена двойным Esc и постоянная история черновиков по Ctrl+P/Ctrl+N; отменённый текст сохраняется.
- Переносимый режим `--sandbox portable` по умолчанию запускает проверки bubblewrap без пользовательского менеджера systemd и делегирования cgroup; `--sandbox strict` сохраняет проверенные общие лимиты cgroup.
- `/security` показывает выбранный режим, действующие лимиты и сниженные гарантии ресурсов переносимого режима.

### Исправлено

- Для Strata добавлен отдельный тип backend: предел контекста определяется по meta.n_ctx вместо поля vLLM max_model_len. Проверены форматы JSON/SSE, фрагменты инструментов, итоговый usage и отключение рассуждений.

- Последовательные сообщения и /edit продолжают текущий диалог с предыдущими ответами и результатами инструментов; контекст очищается явно через /new. Уточнения сохраняют состояние файлов и поддерживают явную загрузку skills.

- Ошибка JSON аргументов теперь сообщает инструмент, размер и позицию без содержимого; отклоняет весь набор вызовов и сохраняет инструкцию для исправления через /continue. Для отклонённого ответа видны расход токенов и finish_reason.

- Для непотоковых ответов чата таймаут ожидания сокета по умолчанию увеличен с общих 120 до 600 секунд; при таймауте явно указаны длительность и действия для продолжения.
- Исправлено распознавание вариантов Home/End в `/edit`; окно с рамкой из линий размещено в нижней половине экрана, заголовок и подсказка перенесены на рамки, текст отправленной задачи выводится перед запуском LLM.
- `/diff` показывает только правки текущей задачи, поэтому файл, созданный ранее в сеансе, не выглядит целиком новым; прежний обзор всего сеанса доступен через `/diff --session [PATH]`.
- Многострочная вставка задачи через GNU Readline с bracketed paste обрабатывается целиком и сохраняется одной записью истории.
- Вывод `/help`, `/help tools` и `/tools` переведён на русский язык; названия команд и инструментов сохранены.
- Перед подтверждением `/apply` показываются только неприменённые файлы и числа добавленных и удалённых строк; полный diff доступен по явной команде `/diff`.
- При повторном запуске подключается последняя совместимая копия с неприменёнными изменениями, поэтому `/apply` больше не работает с новой пустой копией; `--new-session` создаёт новую копию по запросу.
- Вместо автоматического полного diff задачи выводятся числа добавленных и удалённых строк для каждого файла; `/diff [PATH]` показывает один выбранный файл, в том числе по пути из итогового вывода.
- Убраны неподдерживаемые аргументы bubblewrap `--size`; реальные проверки работают с bubblewrap 0.6.3, но у закрытого `/tmp` нет отдельной жёсткой квоты.
- После завершения, блокировки, ошибки, отмены и лимита задачи выводятся абсолютные пути файлов копии и действия `/diff` → `/apply`.
- При запуске и в инструкциях модели явно описаны рабочая копия и перенос в оригинал; повтор одинаковых проверок после отказа инфраструктуры не рекомендуется.

## [1.0.0] - 2026-10-05

### Добавлено

- CLI-агент в одном файле Python 3.8+, использующий только стандартную библиотеку.
- Совместимые с OpenAI адаптеры llama.cpp/vLLM, обнаружение моделей, профили fast/deep и необязательные параметры thinking.
- Инструменты файлов UTF-8, ограниченные просмотр и поиск, точные уникальные правки, атомарная запись и резервные копии исходного содержимого.
- Изолированные копии сеансов, оригинал только для чтения, `/apply` с проверкой конфликтов, `/revert` до начальной базы, `/discard` и явное `/resume`.
- Обязательные проверки в временных снимках bubblewrap: изоляция сети, фиктивный HOME, закрытые временные файлы, чистое окружение, no_new_privs и проверенные ядром лимиты cgroup и ресурсов.
- Компиляция Python, unittest и pytest; синтаксис Bash/ShellCheck и контролируемые автономные проверки синтаксиса/lint Ansible с временными wrapper ролей.
- Явные статусы проверок, диагностика отдельных файлов, отчёт о ресурсах и времени, карантин при неподтверждённой остановке дочерних процессов.
- Правки AUTO/REVIEW, ограниченный цикл модели и инструментов, защита от повторов и сохранение задач.
- Редактирование readline, история по проектам, дополнение TAB и подробный ход инструментов и проверок.
- Статистика токенов ответа и всей задачи, получение предела контекста и явно обозначенная приблизительная оценка заполнения.
- Встроенные локальные self-test и интеграционные тесты с проверкой доступности изоляции.
- Документация кода на английском и русском, README, руководства пользователя и шесть переведённых архитектурных диаграмм.
- Версия 1.0.0 при запуске и команда `--version`.

### Ограничения проверки

- Реальные интеграционные запуски изоляции пропущены в проверочном окружении: службе пользователя недоступен обязательный контроллер `cpu.max`; также отсутствует `ansible-lint`.
- Статические проверки синтаксиса/lint не доказывают корректность выполнения скрипта, converge или идемпотентность Ansible.
- Рост снимка отслеживается, но не ограничивается жёсткой квотой файловой системы; враждебные гонки на хосте с тем же UID находятся вне модели защиты файлов.
